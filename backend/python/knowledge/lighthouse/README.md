# Relatórios Lighthouse para o GameBot

Coloque aqui os relatórios JSON exportados pelo Lighthouse para que o especialista de acessibilidade consiga recuperá-los como evidência.

Para atender à rubrica, registre três execuções da página principal e três de uma página interna (detalhe do jogo ou checkout). Use Chrome anônimo, sem extensões, categoria Accessibility e desktop. O chatbot calcula a mediana das três notas por tipo de página e nunca inventa resultados ausentes.

Sugestão de nomes:

- `principal-1.json`, `principal-2.json`, `principal-3.json`
- `checkout-1.json`, `checkout-2.json`, `checkout-3.json`
